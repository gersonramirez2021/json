Registro Serverless

Formulario de práctica para registrar los datos y descargar un archivo JSON.

Simulación local: este archivo se ejecuta en el navegador; no usa Docker, Kubernetes ni OpenFaaS y no acredita un despliegue en esa plataforma.

El JSON descargado queda en la carpeta de descargas del navegador. Muévelo a la raíz del proyecto si lo necesitas para tu práctica local.
